> 本目录为「汉韵同袍」汉服 APP 的模块级功能与技术文档，据 `docs/“汉韵同袍”汉服APP策划案.docx` 拆解而成，目标是**可据此直接开发**。

| 端 | 技术 | 版本/说明 |
|----|------|-----------|
| 用户端 App | Android + Kotlin + Jetpack Compose | AGP 9.3.0 / Kotlin 2.2.10 / Compose BOM 2026.02.01 / compileSdk 36.1 / minSdk 24 / 包名 `com.example.hytp` |

## 3. 每份模块文档的统一结构

为便于开发，用户端/商家端/管理端的每个模块文档均按以下小节组织：

1. **模块概述**：对应策划案哪一节、解决什么痛点、核心目标。
2. **功能清单**：子功能拆分（feature list），标注优先级 P0/P1/P2。
3. **页面与交互**：涉及的页面、关键交互流程、状态流转。
4. **数据模型**：本模块相关的 MySQL 表（详见 02，本文只列相关子集与字段要点）。
5. **API 接口**：REST 端点定义（方法、路径、入参、出参、错误码）。
6. **端上实现要点**：Android（Compose 页面/ViewModel/Repository）或 Web 的关键实现。
7. **AI/算法接入**（若涉及）：调用的 AI 服务、输入输出契约。
8. **验收标准**：本模块的可测试验收点。

## 4. 术语表

| 术语 | 含义 |
|------|------|
| 同袍 | 汉服爱好者之间的互称，本 App 的核心用户 |
| 形制 | 汉服的款式规范（曲裾、襦裙、袄裙、马面裙等），按朝代分类 |
| 山正 | "山寨/正版"，商家资质与商品原创性的核心风控点 |
| 妆造 | 妆容+造型，文旅与拍摄的关键服务 |
| 跟拍 | 摄影师随行拍摄服务 |
| 品质保障金 | 商家入驻缴纳、用于先行赔付的保证金 |
| 数据驾驶舱 | 商家端基于平台数据的经营分析看板 |

## 5. 优先级与里程碑（对齐策划案发展规划）

- **P0（短期 1–3 月，MVP）**：账号、萌新入门（科普/试穿）、交易区（商城/下单/支付）、基础社交（动态）、商家店铺管理、管理端审核。
- **P1（中期 4–6 月）**：精准匹配与社群、文旅服务、文化传承、数据驾驶舱、营销工具、情感分析。
- **P2（长期 7–12 月）**：AR 试妆、定制共创、供应链对接、推荐算法进阶、自有品牌、开放生态。

> 各模块文档的功能清单会用 P0/P1/P2 标注，MVP 阶段只需实现 P0。
