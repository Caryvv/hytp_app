# 07 用户端 · 同袍社交圈

> 对应策划案「三、（一）2. 同袍社交圈」，打造高粘性社群，规避"社交鸡肋"。

## 1. 模块概述

以内容（动态）+ 关系（关注/私信/社群）+ 活动 + 技能互助构建同袍社交生态，借助兴趣标签精准匹配与个性化推荐提升粘性。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 动态发布/浏览 | P0 | 图文/短视频/直播回放，形制/场景/单品标签，种草关联商品 |
| 点赞/评论/转发/收藏 | P0 | 基础互动 |
| 关注与关注流 | P0 | 关注同袍，关注 Tab 时间线 |
| 精准匹配 | P1 | 兴趣标签推荐同地区/同喜好同袍 |
| 私信/群聊 | P1 | 一对一私信、社群群聊 |
| 社群 | P1 | 地域/形制/兴趣/男性同袍群 |
| 活动广场 | P1 | 线上线下活动，报名/发起 |
| 技能互助/约拍 | P1 | 妆造/摄影/缝纫/考据求助与提供，即时约拍 |
| 内容推荐 | P1 | 情感分析优先推送兴趣内容（13） |

## 3. 页面与交互

### 3.1 社交主页（3 子 Tab）
- **动态**：关注同袍内容流 + 推荐流切换；卡片支持点赞/评论/转发；发布入口（悬浮按钮）。
- **同袍**：按同地区/同形制偏好筛选推荐同袍列表，可私信/加好友。
- **活动**：线上线下活动列表，报名/分享/发起。

### 3.2 动态发布
- 图文/短视频/直播；添加形制/场景/单品标签；可关联商品（种草）；定位城市。
- 发布前走内容审核（先发后审或先审后发，见 12）。

### 3.3 动态详情
- 大图/视频播放、评论区（盖楼）、点赞/收藏/转发、作者信息与关注按钮、关联商品卡片。

### 3.4 私信/群聊
- 会话列表 → 聊天页（文本/图片/表情）；群聊含成员管理（群主/管理员）。

### 3.5 技能互助
- 技能标签筛选（妆造/摄影/缝纫/考据）；发求助/提供帮助；对接自由摄影师即时约拍。

## 4. 数据模型（相关子集）

`feed`、`feed_comment`、`feed_like`、`feed_favorite`、`follow`、`chat_conversation`、`chat_message`、`social_group`、`group_member`、`help_post`、`activity`、`activity_signup`、`user_profile_tag`。

## 6. 端上实现要点（Android）

- `feature/social`：3 子 Tab 用 `TabRow` + `HorizontalPager`；动态流 Paging3；视频用 media3，滑动自动播放/暂停。
- 发布页：多图/视频选择上传 OSS，标签选择器，草稿存 Room。
- 私信：会话列表 + 聊天页，消息本地缓存 Room，未读角标；推送到达刷新。
- 关注/点赞用乐观更新（先改 UI 再请求，失败回滚）。

## 7. AI/算法接入

- 内容推荐：调 13 推荐服务，情感分析模型优先推送用户感兴趣内容。
- 精准匹配：基于 `user_profile_tag`（形制偏好/风格/城市/活动）计算相似同袍。

## 8. 验收标准

- 可发布图文/短视频动态并带标签、关联商品；关注流与推荐流正确区分。
- 点赞/评论/收藏/转发计数准确，乐观更新失败可回滚。
- 精准匹配返回同地区/同形制偏好同袍；可私信建立会话。
- 可创建/加入社群并群聊；可发起与报名活动。
- 敏感内容走审核，违规内容不进入公开流（对齐 12）。
