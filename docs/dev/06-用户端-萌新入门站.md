# 06 用户端 · 萌新入门站

> 对应策划案「三、（一）1. 萌新入门站」，解决「不会选、不会穿、不会搭」的入门门槛。

## 1. 模块概述

面向汉服新手，通过形制科普、入门指南、智能问答、虚拟试穿四大功能降低入门门槛，是拉新与留存的关键。同时覆盖男性爱好者（侠客服饰、甲胄合规科普）。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 形制科普 | P0 | 按朝代分类，图文+短视频，形制对比图，面料/礼仪知识 |
| 入门指南 | P0 | 按性别/预算/需求定制推荐路线 |
| 智能问答 | P1 | AI 解答常见问题，图文/语音提问 |
| 萌新求助社区 | P1 | 向资深同袍提问（与 07 社交打通） |
| 虚拟试穿 | P1 | AI 试衣，上传照片/虚拟形象，调尺码/颜色/配饰 |
| AR 试妆 | P2 | 预览汉服妆造效果 |
| 甲胄合规科普 | P1 | 男性爱好者，规避安全风险 |

## 3. 页面与交互

### 3.1 萌新入门首页
- 标题「萌新指南」，4 模块入口（形制科普、入门路线、智能问答、虚拟试穿），国风图标。

### 3.2 形制科普
- 朝代分类 Tab：秦汉/魏晋/唐/宋/明/其他。
- 列表 → 详情（图文+短视频），标注核心特征、区分要点。
- 「形制对比图」：并排对比曲裾/襦裙/袄裙/马面裙等，避免混淆。
- 面料知识、礼仪规范专题。

### 3.3 入门指南
- 表单：性别 / 预算区间 / 需求（日常/拍照/节日）→ 生成专属路线：推荐款式、店铺、搭配方案。
- 男性：重点推荐侠客服饰、简约日常款、甲胄合规科普。

### 3.4 智能问答
- 输入框（文本/语音/图片），实时返回 AI 答案（调 13 的 QA 服务 + 知识库）。
- 兜底：AI 未命中转「萌新求助」发帖到社区。

### 3.5 虚拟试穿
- 顶部「上传照片 / 选择虚拟形象」；中间试穿预览区；下方汉服选择栏（筛形制/风格）；右侧调节（尺码/颜色/配饰：发簪/披帛/腰封）；底部「保存效果 / 加入购物车」。
- 详见 13 AI 服务的试穿契约。

## 4. 数据模型（相关子集）

`edu_article`（科普/礼仪/面料/甲胄合规）、`edu_qa`（问答知识库/求助帖）、`guide_route`（入门指南路线模板）、`product`（试穿/推荐关联）。

## 5. API 接口

### 形制科普
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/edu/articles` | `?category=&dynasty=` 分页列表 |
| GET | `/edu/articles/{id}` | 详情（图文+视频） |
| GET | `/edu/compare` | 形制对比 `?formes=曲裾,襦裙` |
| GET | `/edu/dynasties` | 朝代分类字典 |

### 入门指南
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/edu/guide` | 入参 `{gender,budgetRange,scene}` → 推荐路线（款式/店铺/搭配） |

### 智能问答
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/edu/qa/ask` | `{question, imageUrl?, audioUrl?}` → AI 答案（调 13）；未命中返回可转求助 |
| GET | `/edu/qa/faq` | 常见问题列表 |
| POST | `/edu/qa/help` | 发「萌新求助」帖到社区 |
| GET | `/edu/qa/help` | 求助帖列表 |
| POST | `/edu/qa/help/{id}/answer` | 资深同袍回答 |

### 虚拟试穿
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/tryon/submit` | `{userPhotoUrl|avatarId, productId, sku:{size,color}, accessories:[]}` → 返回任务 id |
| GET | `/tryon/result/{taskId}` | 轮询试穿结果图；含状态（处理中/成功/失败） |
| GET | `/tryon/avatars` | 预置虚拟形象列表 |

> 试穿为异步：submit 入队 → AI 服务渲染 → 轮询或推送获取结果（见 13）。

## 6. 端上实现要点（Android）

- `feature/beginner`：入口页 4 卡片；科普用朝代 Tab + Paging 列表 + 详情（Coil 图 + media3 视频）。
- 智能问答：聊天式 UI（`LazyColumn` 气泡），语音用系统录音上传 OSS 后传 URL；图片同理。
- 虚拟试穿在 `feature/tryon`：CameraX/相册取图 → 上传 OSS → submit → loading 轮询 → 结果页可保存/加购。
- 甲胄相关内容加合规提示 banner（对齐风险控制）。

## 7. AI/算法接入

- 智能问答：调 13 的 `/ai/qa`（知识库检索 + LLM 生成），带汉服领域知识库。
- 虚拟试穿/AR 试妆：调 13 的 `/ai/tryon`、`/ai/makeup`，异步任务。

## 8. 验收标准

- 形制科普按朝代正确分类，对比图可并排查看 ≥2 种形制。
- 入门指南按性别/预算/需求返回差异化推荐，男性能拿到侠客/甲胄合规内容。
- 智能问答文本/图片/语音均可提问并得到响应，未命中可一键转求助。
- 虚拟试穿从选图到出效果图全流程可用，可调尺码/颜色/配饰并加购。
