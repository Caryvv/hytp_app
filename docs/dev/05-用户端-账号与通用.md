# 05 用户端 · 账号与通用

> 对应策划案「十、UI 模型图」中的启动页、登录/注册页、首页、我的页面，以及「五、盈利模式」中的会员服务。

## 1. 模块概述

账号体系是全平台的入口与身份基础，通用模块（启动、首页、我的、会员、消息、设置）串联各业务。目标：极简注册、多端统一身份、未登录可浏览。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 启动页 | P0 | 缠枝纹背景 + LOGO + Slogan，3s 可跳过 |

## 3. 页面与交互

### 3.1 启动页
- 展示 3 秒或点击跳过 → 首页；首次启动展示隐私协议弹窗（合规）。
- 后台静默校验本地 token 有效性，决定进入登录态。

### 3.2 登录/注册页
- Tab：验证码登录 / 密码登录；第三方登录入口（微信/QQ）。
- 注册即登录：手机号未注册时，验证码校验通过后引导设置密码并创建账号。
- 底部提示「新人注册即送新人礼包」。

### 3.3 首页
- 顶部搜索栏（搜汉服/商家/攻略/同袍）→ 统一搜索页。
- 轮播图（banner）：活动/新品/文旅套餐。
- 功能导航区 5 入口：萌新入门、同袍社交、汉服商城、文旅服务、文化传承。
- 个性化推荐流：根据用户偏好混合推荐穿搭/科普/活动/商家（见 13）。
- 下拉刷新；底部 Tab 4 个。

### 3.4 我的页面
- 头像、昵称、会员等级；功能区：我的订单（购买/租赁/定制/文旅分类）、收藏、关注、消息中心、设置、客服。
- 设置页：账号管理、隐私设置、通知设置、意见反馈。

## 5. API 接口

### 认证
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/sms/send` | 发送验证码 `{phone, scene}` |
| POST | `/auth/login` | 验证码/密码登录，注册合一 |
| POST | `/auth/oauth` | 第三方登录 `{provider, code}` |
| POST | `/auth/refresh` | 刷新 token |
| POST | `/auth/logout` | 退出（拉黑 refreshToken） |

`/auth/login` 请求：`{ phone, code?, password?, loginType }`
响应：`{ accessToken, refreshToken, expiresIn, user:{id,nickname,avatar,memberLevel}, isNewUser }`
`isNewUser=true` 时前端弹新人礼包。

### 用户资料
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/user/profile` | 当前用户信息 |
| PUT | `/user/profile` | 改昵称/头像/性别/城市 |
| GET | `/user/addresses` / POST/PUT/DELETE | 收货地址 CRUD |
| GET | `/notifications` | 消息列表（按 type 筛选、分页） |

## 6. 端上实现要点（Android）

- `feature/auth`：`LoginScreen` + `LoginViewModel`，验证码倒计时用 flow；登录成功写 token 到 DataStore，更新全局登录态（`AppStateHolder` / DI 单例）。
- 未登录拦截：`requireLogin { navigate(...) }`，未登录跳 `LoginScreen` 并回跳。
- `feature/home`：`HomeScreen` 用 `LazyColumn` 组合轮播（HorizontalPager）+ 导航九宫格 + Paging3 推荐流。
- `feature/mine`：订单入口按 type 跳订单列表（见 08）。
- 会员购买复用支付流程（见 08 支付章节）。

## 7. 会员权益（对齐策划案）

高级会员（9.9/月 或 99/年）：免运费、专属优惠券、优先定制、免费课程、专属社群。权益校验在各业务 Service 层读 `user.member_level` + `member_expire_at`。

## 8. 验收标准

- 新手机号一次验证码即可完成注册并登录，返回 `isNewUser=true` 且自动发放新人券。
- token 过期能自动续签，续签失败跳登录且不丢失当前页面意图。
- 未登录可浏览科普/活动/商品，点击下单/发动态/私信被拦截跳登录。
- 首页推荐流分页流畅，下拉刷新生效。
- 开通会员后权益（免运费等）在下单时正确生效。
