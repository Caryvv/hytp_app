# 08 用户端 · 汉服交易区

> 对应策划案「三、（一）3. 汉服交易区」，解决"买不到好货、怕踩雷"，合规、透明。

## 1. 模块概述

平台核心变现模块，涵盖分类商城、商家筛选与信用、购物车、下单支付、租赁、定制、交易保障（品质保障金、七天无理由）。佣金 5%-8%。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 分类商城 | P0 | 形制/风格/价格/用途分类，售卖/租赁区分 |
| 商品详情 | P0 | 图文、规格、虚拟试穿入口、评价、商家信息 |
| 商家筛选与信用 | P0 | 口碑/销量/产地筛选，信用体系、差评率公示 |
| 购物车/下单 | P0 | SKU、地址、优惠券、结算 |
| 支付 | P0 | 微信/支付宝 |
| 订单管理 | P0 | 购买/租赁/定制/文旅分类，售后退换 |
| 租赁 | P1 | 租期选择、押金、归还 |
| 交易保障 | P1 | 品质保障金先行赔付、七天无理由 |
| 定制/共创 | P2 | 需求发布、设计师竞标、进度跟踪、联名款 |
| 高性价比推荐 | P1 | 销量聚类模型推荐爆款（13） |

## 3. 页面与交互

### 3.1 汉服商城页
- 顶部分类导航（形制/风格/价格/租赁·售卖）；商家筛选栏（口碑/销量/产地）。
- 商品卡片：图、名、价、商家标签、好评率；下拉分页。

### 3.2 商品详情页
- 图文介绍、规格选择（SKU：尺码/颜色）、虚拟试穿入口、评价区（含情感关键词标签）、商家信息与信用。
- 操作：加入购物车、立即购买、预约租赁。

### 3.3 结算/下单
- 选地址、SKU、数量、优惠券、会员权益（免运费）；展示佣金对用户透明可不显示，仅内部记录。
- 提交订单 → 调起支付。

### 3.4 订单列表/详情
- 按 type 分类 Tab：购买/租赁/定制/文旅。
- 状态流转、物流、售后入口、评价入口。

### 3.5 定制
- 发布定制需求（预算/截止/图）→ 设计师竞标列表 → 选中 → 进度跟踪。

## 4. 订单状态机

```
待付款(0) ──支付──▶ 待发货(1) ──发货──▶ 待收货(2) ──确认──▶ 已完成(4)
   │                                                        │
   └──取消──▶ 已取消(5)                        售后：申请→处理→退款(6)
租赁额外：待发货→使用中→待归还→已归还→已完成
定制额外：待接单→制作中→待发货→...
```

- 佣金在订单完成（确认收货/核销）后结算入平台账，记 `shop_order.commission`。
- 品质保障金：判定"山品/质量不符"成立 → 平台先行赔付，扣商家 `deposit`（记 `deposit_claim`）。

## 5. 数据模型（相关子集）

## 6. API 接口

|------|------|------|

| GET | `/products/recommend` | 高性价比爆款推荐（13） |

### 购物车/下单/支付
| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST/PUT/DELETE | `/cart` | 购物车 CRUD |
| POST | `/orders/preview` | 结算预览（金额/优惠/运费/会员权益） |

## 7. 端上实现要点（Android）

- `feature/shop`：商城页（分类导航 + 筛选 + Paging 卡片）、详情页、购物车、结算页、订单列表/详情、售后、定制。
- 支付：接微信/支付宝 SDK，`/pay` 拿参数唤起，结果页轮询订单状态（不以客户端回调为准，以服务端 notify 改单为准）。
- 下单幂等：客户端生成 `Idempotency-Key`，防重复提交。
- 评价页支持晒图（OSS），提交后展示情感关键词标签。

## 8. 交易保障与合规

- 七天无理由：定制款明确不支持标注；退换规则在详情页展示。
- 品质保障金：赔付流程见 12 管理端；商家信用分随差评/违规变动，详情页公示差评率与"线头/色差/炸褶"改进情况。
- 商家资质校验（原创证明/生产资质）见 11、12。

## 9. 验收标准

- 商品可按形制/风格/价格/用途/租售筛选，商家可按口碑/销量/产地筛选。
- 完整下单→支付→发货→确认→评价链路可用，支付以服务端回调改单为准，幂等无重复扣款。
- 租赁含租期/押金；定制可竞标选标并跟踪。
- 确认收货后正确结算佣金；判定山品可触发保障金赔付并扣商家保证金。
- 评价提交后异步产出情感标签，展示在详情评价区。
