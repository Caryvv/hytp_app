# 12 管理员端 · Web 管理台

> 对应策划案「三、（三）管理员端」与「十、（二）管理端 UI 模型图」。Web 端（Vue3 + Element Plus），后端 `admin/` 入口，左侧导航 + 右侧内容区经典布局。

## 1. 模块概述

平台管控中枢：数据驾驶舱、用户/商家/内容/订单管理、数据监控、系统设置，保障生态健康与合规。基于 RBAC 权限（超级管理员/普通管理员）。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 管理首页（数据驾驶舱） | P0 | 核心指标概览 + 核心提醒 |
| 用户管理 | P0 | 审核、投诉处理、封禁、行为记录 |
| 商家管理 | P0 | 入驻审核、商品排查、违规处罚、保证金 |
| 内容管理 | P0 | 动态/科普/攻略审核，推荐算法配置 |
| 订单管理 | P1 | 全平台订单查询、售后干预、导出 |
| 数据监控 | P1 | 用户/商家/交易/内容多维数据 |
| 系统设置 | P1 | 管理员/权限、平台参数、消息推送、接口、日志 |

## 3. 页面与交互

### 3.1 登录
- 管理员账号密码登录（区分超级/普通管理员），密码找回。

### 3.2 管理首页（数据驾驶舱）
- 顶部核心数据（用户总数/活跃/商家/交易额/订单数/投诉数），折线/柱状/饼图，今日/昨日/近7日/近30日。
- 核心提醒卡片：待审核商家、待处理投诉、异常订单 → 点击进对应处理页。

### 3.3 用户管理
- 筛选（性别/年龄/注册时间/状态）+ 列表（ID/昵称/手机/注册时间/状态）；批量禁用/启用、搜索、查看详情（行为/订单记录）、处理投诉。

### 3.4 商家管理（3 子模块）
- 商家审核：待审信息（名称/资质/入驻类型）→ 通过/驳回（填理由）。
- 商家列表：所有商家（名称/类型/资质/信用/交易额）→ 编辑/禁用/删除、查看详情与订单。
- 违规处理：违规信息+原因 → 处罚/下架商品/扣保证金。

### 3.5 内容管理（3 子模块）
- 动态审核：用户动态审核通过/驳回/删除。
- 科普内容：上传/编辑/删除科普图文/短视频，按朝代/类型分类。
- 攻略管理：审核/编辑/推荐出行攻略。

### 3.6 订单管理
- 筛选（类型/状态/时间/商家）+ 列表；查看详情、处理售后、导出、异常订单手动干预。

### 3.7 数据监控（4 子模块）
- 用户数据（增长趋势）、商家数据（销量排名）、交易数据（时段分布）、内容数据；图表 + 筛选 + 导出。

### 3.8 系统设置
- 管理员账号管理（增删改、分配权限）、平台参数（佣金比例/保证金/活动规则）、消息推送、接口管理、日志（操作/异常日志）。

## 4. 数据模型（相关子集）

`admin_user`、`admin_role`、`admin_role_permission`、`admin_operation_log`、`sys_config`、`data_stat_daily`、`report`，以及对 `user`/`shop`/`product`/`feed`/`shop_order`/`edu_article`/`travel_guide` 的管理操作。

## 5. API 接口（admin 入口，路径前缀 `/admin`）

### 登录与首页
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/admin/auth/login` | 管理员登录 |
| GET | `/admin/dashboard` | 概览指标 + 核心提醒 |

### 用户管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/users` | 列表（筛选） |
| GET | `/admin/users/{id}` | 详情（行为/订单） |
| POST | `/admin/users/{id}/ban` / `unban` | 封禁/解封 |
| GET | `/admin/reports` | 投诉/举报列表 |
| POST | `/admin/reports/{id}/handle` | 处理举报 |

### 商家管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/shops` | 商家列表 |
| POST | `/admin/shops/{id}/audit` | 审核通过/驳回 |
| POST | `/admin/shops/{id}/punish` | 处罚（下架/扣保证金/封禁） |
| POST | `/admin/deposit-claims/{id}/approve` | 保证金赔付审批 |

### 内容管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/feeds` | 待审动态 |
| POST | `/admin/feeds/{id}/audit` | 通过/驳回/删除 |
| GET/POST/PUT/DELETE | `/admin/edu/articles` | 科普内容 CRUD |
| POST | `/admin/travel/guides/{id}/audit` | 攻略审核/推荐 |
| POST | `/admin/courses/{id}/audit` | 课程审核 |

### 订单与数据
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/orders` | 全平台订单 |
| POST | `/admin/orders/{orderNo}/intervene` | 异常干预 |
| GET | `/admin/orders/export` | 导出 |
| GET | `/admin/stats/{dimension}` | 用户/商家/交易/内容数据 |

### 系统设置
| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST/PUT/DELETE | `/admin/admins` | 管理员账号 |
| GET/PUT | `/admin/roles` | 角色权限 |
| GET/PUT | `/admin/configs` | 平台参数（佣金/保证金/规则） |
| GET | `/admin/logs` | 操作/异常日志 |

## 6. 权限（RBAC）

- 角色：超级管理员（全权）、普通管理员（按分配的 `permission_key`）。
- 权限点粒度到操作（如 `shop:audit`、`user:ban`、`config:edit`）。
- 所有写操作记 `admin_operation_log`（谁/什么/何时/IP）。

## 7. 数据监控闭环

对齐策划案「数据采集—多模态分析—场景化策略生成」：管理端数据监控消费 `data_stat_daily` 与实时聚合，异常告警，指导运营与平台功能优化（见 13）。

## 8. 验收标准

- 数据驾驶舱指标准确，核心提醒可跳转处理页。
- 用户/商家/内容/订单的审核、处罚、干预操作生效并记日志。
- 商家审核驳回需填理由；违规可下架商品并扣保证金。
- RBAC 生效：普通管理员无越权操作；超级管理员可管理账号与权限。
- 平台参数（佣金比例等）修改后对交易结算生效。
