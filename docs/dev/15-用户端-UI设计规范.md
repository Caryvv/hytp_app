# 汉韵同袍汉服APP - UI设计规范

> **版本**：v1.0  
> **更新日期**：2026-08-03  
> **设计风格**：新中式（Neo-Chinese）国风设计  
> **一句话气质**：如宣纸上的一抹黛青，克制、雅致、有呼吸感，不喧宾夺主

---

## 一、设计概述

### 1.1 设计理念

**三个关键词：雅（Elegant）、透（Airy）、韵（Cultural）**

- **雅**：审美克制，不堆砌元素，留白充足，符合中式"少即是多"的哲学
- **透**：层级轻盈，避免厚重阴影，用描边+极浅阴影表达层级
- **韵**：文化元素融入细节（盘扣、缠枝纹、回纹、铜钱），不喧宾夺主

### 1.2 设计原则

1. **一处点睛**：单屏朱红色面积占比不超过15%，仅用于关键CTA和强调
2. **呼吸感**：页面水平边距16dp，区块间距24dp，留白充足
3. **国风克制**：传统元素用于装饰和隐喻，不做大面积图案堆砌
4. **一致性**：统一的圆角、间距、字阶、色彩体系

- 朱红面积占比单屏 > 15%
- 在服饰图片上直接铺色块（用半透明scrim渐变代替）

## 三、字体与排印

### 3.1 字体家族

| 用途 | 字体 | 说明 |
|------|------|------|
| 品牌标题/大标题 | 霞鹜文楷（开源可商用） | 书法/宋体风格，用于品牌展示 |

## 四、形状、间距与层级

### 4.1 圆角（Shape）

| 规格 | 圆角值 | 用途 |
|------|--------|------|
| `extraSmall` | 6 dp | Chip、小标签、角标 |
| `small` | 10 dp | 输入框、小按钮 |
| `medium` | 14 dp | 卡片、对话气泡 |
| `large` | 20 dp | 大卡片、底部弹窗（顶部圆角） |
| `extraLarge` | 28 dp | 图片容器、Banner |

### 4.2 间距（Spacing，8dp栅格）

| 场景 | 间距值 |
|------|--------|
| 页面水平边距 | 16 dp |
| 卡片内边距 | 12–16 dp |
| 区块之间 | 24 dp |
| 列表项垂直间距 | 12 dp |

### 4.3 层级与阴影（Elevation）

国风讲究"轻"，避免重投影，多用描边 + 极浅阴影表达层级。

| 层级 | 高度 | 说明 |
|------|------|------|
| 页面底 | 0 dp | background色 |
| 卡片 | 1 dp | surface + 1px outlineVariant描边 |
| 顶栏/底栏 | 2 dp | surface，滚动时出现细分割线 |
| 悬浮按钮/弹窗 | 3–6 dp | 柔和阴影 |

## 五、通用组件规范

### 5.1 HanfuButton（主行动按钮）

**形态**：胶囊/圆角矩形

**变体**：
- **Primary**：填充primary（黛青），文字onPrimary — 常规主操作
- **Emphasis**：填充tertiary（朱红），文字白色 — 关键CTA，一屏一个
- **Outline**：描边primary，文字primary — 次级操作
- **Text**：纯文字primary — 三级操作

**规格**：
- 大按钮：高度48dp，文字labelLarge
- 中按钮：高度40dp，文字labelLarge
- 小按钮：高度32dp，文字labelMedium

**可选装饰**：左侧可挂"盘扣"矢量图标

### 5.2 HanfuCard（内容卡片）

**样式**：surface底 + 1px outlineVariant描边 + medium(14dp)圆角 + 1dp elevation

**变体**：
- `ProductCard`：商品卡片
- `FeedCard`：动态卡片
- `CourseCard`：课程卡片
- `EntryCard`：功能入口卡片

### 5.3 DynastyTag（朝代/形制标签）

**样式**：小圆角Chip（extraSmall 6dp）

**语义色区分**：
- 朝代：青瓷底（secondaryContainer）+ onSecondaryContainer文字
- 山正认证：朱红描边 + "正"字 + 小印章
- 会员：缃黄底 + 深色文字

### 5.4 SectionTitle（区块标题）

**组成**：左侧一枚"缠枝纹/卷草"细矢量装饰 + 标题（headlineSmall，Brand字体）+ 右侧可选"更多 ›"

### 5.5 SearchBar（统一搜索）

**样式**：圆角small(10dp)，底surfaceVariant

**组成**：左侧搜索图标 + 占位文案「搜汉服 / 商家 / 攻略 / 同袍」

### 5.6 底部导航（BottomBar）

**5个Tab**：首页 / 社交 / 智能问答（中间） / 商城 / 我的

**样式**：
- 底surface + 顶部1px outlineVariant
- 选中图标+文字primary（黛青），未选中onSurfaceVariant
- 图标风格：线性国风图标（描边统一2dp圆头），选中态可切换为填充
- **「智能问答」中间用朱红盘扣造型突出显示**
