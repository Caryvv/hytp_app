# 15 用户端 · UI 设计规范（国风设计系统）

> 本文为「汉韵同袍」用户端 App 的**视觉与交互设计系统（Design System）**，据策划案「十、UI 模型图」与 04《Android 客户端架构》§7「主题与国风设计」细化而成，目标是**可直接据此落地 Jetpack Compose 主题与组件**。
>
> 当前代码基线：`ui/theme` 仍为脚手架默认的 Material3 紫/粉配色（`Purple40/80` 等）。本规范给出替换后的完整国风 Token 体系与组件契约。

---

## 1. 设计理念与定位

「汉韵同袍」是「工具 + 交易 + 社交 + 文化」四位一体的汉服生态平台。UI 定位为 **「新中式（Neo-Chinese）」**：以传统色彩、纹样、留白意境为骨，以现代 Material 3 的可用性、无障碍与响应式为肉。

**一句话气质**：如宣纸上的一抹黛青，克制、雅致、有呼吸感，不喧宾夺主。

三个关键词：

- **雅（Elegant）**：低饱和传统色为主，朱红点睛，避免大面积高饱和撞色。
- **透（Airy）**：大留白、疏朗排布，让内容（服饰图片/短视频）成为主角。
- **韵（Cultural）**：盘扣、披帛、缠枝纹、卷轴等文化符号作为点缀，不做主视觉噪音。

---

## 2. 设计原则

1. **内容优先**：汉服图片、短视频是核心资产。容器（卡片/背景）保持素净，用留白和圆角衬托图片，禁止在图片上叠加高饱和色块。
2. **一处点睛**：单屏内朱红（品牌强调色）只用于**最重要的一个动作**（如"立即购买""发布""关注"），滥用会失去引导力。
3. **克制的国风**：纹样只出现在启动页、空态、分割线、区块标题等"过渡场景"，不进入高频操作区。
4. **一致而不失层次**：全局复用同一套 Token（色/字/间距/圆角/阴影），通过层级（Surface Elevation）区分信息主次。
5. **无障碍达标**：正文文本与背景对比度 ≥ 4.5:1，大字 ≥ 3:1；可点击区域 ≥ 48dp。
6. **明暗双主题**：所有颜色成对定义（Light/Dark），夜间以"墨夜"基调替换"月白"底。

### 3.3 动态取色（Dynamic Color）

- **关闭 Android 12+ 动态取色**（当前 `Theme.kt` 默认开启，需改为默认 `dynamicColor = false`）。理由：品牌国风调性需要强一致性，系统取色会破坏"黛青+朱红"的识别度。
- 保留 `darkTheme` 跟随系统。

### 3.4 用色红线

- ❌ 不用纯黑 `#000000` 做文本（改用 `MoHei`），不用纯白 `#FFFFFF` 做大面积底（改用 `YueBai`）。
- ❌ 朱红面积占比单屏 > 15%。
- ❌ 在服饰图片上直接铺色块（用半透明 `scrim` 渐变代替）。

## 4. 字体与排印（Typography）

### 4.1 字体家族

| 场景 | 字体 | 说明 |
|------|------|------|
| 品牌标题 / 大标题 | 书法/宋体风格自带字体（`res/font`，如"霞鹜文楷"等开源可商用字体） | 用于启动页 Slogan、模块大标题、区块标题 |
| 正文 / 控件 | 系统默认（`FontFamily.Default`，思源黑/系统无衬线） | 保证清晰与信息密度 |
| 数字 / 价格 | 系统默认，等宽倾向 | 价格用 `tertiary` 色 + Medium 字重 |

> 落地：字体文件放 `app/src/main/res/font/`，在 `Type.kt` 定义 `val SerifBrand = FontFamily(Font(R.font.xxx))`；标题类样式引用它，正文类用 `FontFamily.Default`。字体缺失时优雅降级到系统衬线体。

### 4.2 字阶（Type Scale，映射 Material 3 Typography）

| Role | 字号/行高 | 字重 | 字体 | 用途 |
|------|-----------|------|------|------|
| `displaySmall` | 32 / 40 | SemiBold | Brand | 启动页 Slogan、空态大标题 |
| `headlineMedium` | 26 / 34 | SemiBold | Brand | 模块首页大标题（如"萌新指南"） |
| `headlineSmall` | 22 / 30 | Medium | Brand | 页面主标题、区块标题 |
| `titleLarge` | 20 / 28 | Medium | Default | 卡片标题、对话页标题 |
| `titleMedium` | 16 / 24 | Medium | Default | 列表项标题、Tab |
| `bodyLarge` | 16 / 24 | Normal | Default | 正文（沿用现有基线）|
| `bodyMedium` | 14 / 20 | Normal | Default | 次要正文、描述 |
| `bodySmall` | 12 / 16 | Normal | Default | 辅助说明、时间戳 |
| `labelLarge` | 14 / 20 | Medium | Default | 按钮文字 |
| `labelMedium` | 12 / 16 | Medium | Default | 标签 Chip、角标 |
| `labelSmall` | 11 / 16 | Medium | Default | 底部 Tab 文字、微标 |

- 中文字间距（`letterSpacing`）标题设 `0.sp`，正文 `0.2.sp`；避免默认拉丁字距过大导致中文松散。

## 5. 形状、间距与高度（Shape / Spacing / Elevation）

### 5.1 圆角（Shape）

国风偏"温润"，圆角适中偏大，避免尖锐。映射 Material 3 `Shapes`：

| Token | 半径 | 用途 |
|-------|------|------|
| `extraSmall` | 6dp | Chip、小标签、角标 |
| `small` | 10dp | 输入框、小按钮 |
| `medium` | 14dp | 卡片、对话气泡 |
| `large` | 20dp | 大卡片、底部弹窗（顶部圆角） |
| `extraLarge` | 28dp | 图片容器、Banner |

- 按钮：主按钮用 `small`（10dp）或"盘扣"胶囊态（见 6.1）。
- BottomSheet：顶部 `large`（20dp）。

### 5.2 间距（Spacing，8dp 栅格）

统一 8dp 基准：`Spacing.xs=4 / sm=8 / md=12 / lg=16 / xl=24 / xxl=32`。

- 页面水平边距：**16dp**。
- 卡片内边距：**12–16dp**。
- 区块（Section）之间：**24dp**。
- 列表项垂直间距：**12dp**。

### 5.3 层级与阴影（Elevation）

国风讲究"轻"，避免重投影，多用**描边 + 极浅阴影**表达层级。

| 层级 | Elevation | 表现 |
|------|-----------|------|
| 页面底 | 0 | `background` |
| 卡片 | 1dp | `surface` + 1px `outlineVariant` 描边，阴影几乎不可见 |
| 顶栏/底栏 | 2dp | `surface`，滚动时出现细分割线而非重阴影 |
| 悬浮按钮/弹窗 | 3–6dp | 柔和阴影 |

## 6. 通用组件规范（core/ui）

> 组件统一放 `com.example.hytp.core.ui`，命名带 `Hanfu`/语义前缀。以下为**契约（API + 视觉）**，不含实现代码。

### 6.1 HanfuButton（主行动按钮）

- **形态**：胶囊/圆角矩形；主态填充 `primary`（黛青），文字 `onPrimary`；**点睛态**（关键 CTA）填充 `tertiary`（朱红）。
- **变体**：`Primary`（填充）、`Emphasis`（朱红填充，一屏一个）、`Outline`（描边，`outline` + `primary` 文字）、`Text`（纯文字）。
- **可选装饰**：左侧可挂"盘扣"矢量图标（`ic_pankou`），仅用于品牌感强的入口按钮，列表内按钮不加。
- **规格**：高度 48dp（大）/ 40dp（中）/ 32dp（小）；文字 `labelLarge`；按压态叠加 8% `onPrimary`/`onSurface`。
- **禁用态**：底 `surfaceVariant`，文字 `TuoHui`。

### 6.2 HanfuCard（内容卡片）

- `surface` 底 + 1px `outlineVariant` 描边 + `medium`(14dp) 圆角 + 1dp elevation。
- 可选顶部图片区（`extraLarge` 圆角仅上方，或整卡统一圆角裁切图片）。
- 变体：`ProductCard`（商品）、`FeedCard`（动态）、`CourseCard`（课程）、`EntryCard`（功能入口）。

### 6.3 DynastyTag（朝代/形制标签）

- 小圆角 Chip（`extraSmall` 6dp），`secondaryContainer` 底 + `onSecondaryContainer` 文字，`labelMedium`。
- 语义色区分：朝代（青瓷底）、山正认证（朱红描边+"正"字）、会员（缃黄底）。
- 用于形制科普、商品、图鉴的分类标注。

### 6.4 SectionTitle（区块标题）

- 左侧一枚"缠枝纹/卷草"细矢量装饰（8×20dp）+ 标题（`headlineSmall`，Brand 字体）+ 右侧可选"更多 ›"（`bodyMedium`，`onSurfaceVariant`）。
- 装饰使用 `primary` 30% 透明度，克制。

### 6.5 SearchBar（首页/统一搜索）

- 圆角 `small`(10dp)，底 `surfaceVariant`，左侧搜索图标 `onSurfaceVariant`，占位文案「搜汉服 / 商家 / 攻略 / 同袍」。
- 首页顶栏内联；点击进入统一搜索页（对应 `/search`）。

### 6.6 状态组件（对齐 04 §9）

| 组件 | 视觉 |
|------|------|
| `LoadingView` | 居中 `CircularProgressIndicator`（`primary` 色）+ 可选"加载中"`bodyMedium`；国风增强：可用旋转的"团扇/铜钱"矢量替代默认圈（P1） |
| `EmptyView` | 居中缠枝纹/空卷轴插画（`TuoHui` 线稿）+ 文案 + 可选行动按钮 |
| `ErrorView` | 插画 + 错误文案（`onSurfaceVariant`）+「重试」`Outline` 按钮 |
| `PullToRefresh` | Material3 `PullToRefreshBox`，指示器 `primary` 色 |

### 6.7 底部导航（BottomBar）

- 4 Tab：**首页 / 社交 / 商城 / 我的**（对齐 04 §6）。
- 底 `surface` + 顶部 1px `outlineVariant`；选中图标+文字 `primary`（黛青），未选中 `onSurfaceVariant`。
- 图标风格：**线性国风图标**（描边统一 2dp 圆头），选中态可切换为填充。文字 `labelSmall`。
- 「发布」可选做中间凸起 FAB（朱红盘扣造型），用于社交发动态（P1）。

### 6.8 顶栏（TopAppBar）

- 小标题居左（Brand 字体），底 `surface`，无重阴影；滚动上滑时显示细分割线。
- 返回箭头 `onSurface`；右侧动作图标 `onSurfaceVariant`。

### 6.9 其他复用件

- **PriceText**：价格用 `tertiary`（朱红）+ Medium，`¥` 符号小一号。
- **RatingBar / 好评率**：星标 `TuoHuang`（缃黄）。
- **AvatarRing**：会员头像加缃黄描边环；普通无环。
- **CouponCard（新人礼包/优惠券）**：朱红系 `tertiaryContainer` 底，票券缺口造型。
- **TagFlow**：形制/场景/单品标签的流式布局，用于动态发布与商品。

## 7. 各页面视觉规范（对应 04 §8 关键页面）

### 7.1 启动页（Splash）— feature/splash · 文档 05

- 全屏 `YueBai` 底，居中 LOGO + Slogan（`displaySmall`，Brand）。
- 背景**缠枝纹**水印（`primary` 8% 透明），四角或中心淡出。
- 右上角「跳过 3s」文字按钮（`onSurfaceVariant`）。首次启动叠加隐私协议弹窗。

### 7.2 登录/注册 — feature/auth · 文档 05

- 顶部品牌区（LOGO + 一句 Slogan）；`Tab`：验证码登录 / 密码登录。
- 输入框 `surfaceVariant` 底 `small` 圆角；主按钮「登录 / 注册」用 `Primary`（黛青）。
- 第三方登录（微信/QQ）圆形图标居中排列，上方细分割线 +「其他方式登录」。
- 底部朱红文字提示「新人注册即送新人礼包」。

### 7.3 首页 — feature/home · 文档 05

结构（`LazyColumn`）：

1. 顶栏：SearchBar + 右侧消息铃铛（未读朱红角标）。
2. Banner 轮播（`HorizontalPager`，`extraLarge` 圆角，页码圆点 `primary`）。
3. 功能导航九宫格/一行 5 入口：**萌新入门 / 同袍社交 / 汉服商城 / 文旅服务 / 文化传承**，`EntryCard` + 线性国风图标 + 文字。
4. 个性化推荐流（Paging3）：混排穿搭动态 / 科普 / 活动 / 商家，卡片复用 `FeedCard`/`ProductCard`。
5. 支持下拉刷新。

> 当前 `HomeScreen` 是占位实现（欢迎语 + 几个按钮），需按此结构重构。

### 7.4 萌新入门站 — feature/beginner · 文档 06

- 首页：大标题「萌新指南」（`headlineMedium`）+ 4 张 `EntryCard`（形制科普 / 入门路线 / 智能问答 / 虚拟试穿），每卡配国风插画。
- 形制科普：顶部朝代 `TabRow`（秦汉/魏晋/唐/宋/明/其他）+ Paging 列表 + `DynastyTag`。
- 智能问答：聊天气泡（`medium` 圆角，本人 `primaryContainer` 右对齐，AI `surfaceVariant` 左对齐）。
- 甲胄合规内容顶部加 `tertiaryContainer` 合规提示 banner。

### 7.5 同袍社交圈 — feature/social · 文档 07

- 3 子 Tab（`TabRow`+`HorizontalPager`）：动态 / 同袍 / 活动。
- 动态流 `FeedCard`：作者行（`AvatarRing`+昵称+关注按钮）→ 图/视频（`extraLarge` 圆角，多图九宫格）→ 文案 → 标签 `TagFlow` → 互动行（点赞/评论/转发/收藏，选中态朱红）。
- 悬浮发布 FAB（朱红盘扣）。
- 私信/群聊：会话列表 + 聊天气泡页（同 7.4 气泡规范），未读角标朱红。

### 7.6 汉服商城 — feature/shop · 文档 08

- 商城页：顶部分类导航 + 商家筛选栏（`FilterChip`，选中 `primaryContainer`）；商品双列瀑布 `ProductCard`（图 + 名 2 行省略 + `PriceText` + 商家标签 + 好评率）。
- 商品详情：顶部图册 `HorizontalPager` → 标题/价格 → SKU 选择（尺码/颜色 `FilterChip`）→ 虚拟试穿入口按钮 → 评价区（情感关键词 Chip）→ 商家信用卡片（含 `DynastyTag` 山正认证/差评率）。
- 底部操作栏：`加入购物车`（Outline）+ `立即购买`（Emphasis 朱红）。
- 结算/订单：清单卡片 + 金额明细（会员免运费高亮）；订单列表按 type 分 Tab；状态用语义色文字。

### 7.7 文旅服务站 — feature/travel · 文档 09

- 3 子 Tab：本地服务 / 文旅套餐 / 出行攻略。
- 本地服务：地图（高德 SDK）+ 下方 POI 列表联动，距离/口碑/营业时间；预约用底部弹窗选时段。

## 8. 图标与插画

- **图标**：统一线性风格，描边 2dp 圆头圆角，栅格 24dp。功能导航、Tab、列表尽量用同一套；关键文化符号（盘扣、披帛、团扇、缠枝纹、卷轴、铜钱、印章）做成矢量 `drawable` 备用。
- **选中态**：Tab 与互动图标选中可切填充态。
- **插画**：空态/引导/启动页使用线稿国风插画（`TuoHui`/`primary` 低饱和），风格统一，避免写实照片当插画。
- 图标资源建议放 `res/drawable`（矢量）；复杂插画走 OSS 远程图，用 Coil 加载。

---

## 9. 动效规范

- **克制、自然**，时长 200–300ms，缓动用 Material `FastOutSlowIn`。
- 页面转场：标准滑入/淡入；BottomSheet 上滑。
- 点赞/收藏：轻微缩放回弹 + 朱红染色（乐观更新，失败回滚）。
- 列表首屏：错落淡入（可选，低端机降级关闭）。
- 视频列表：滑动进入视口自动播放/暂停（media3）。
- 骨架屏（Shimmer）：图片/卡片加载用 `surfaceVariant` 微光扫过，替代空白。

---

## 10. 深色模式与无障碍

- 深色主题用 §3.2 Dark 表；图片不反色，靠底色切换。启动/空态插画准备深色变体或用可自适应的单色矢量。
- **对比度**：正文 ≥ 4.5:1，大字/图标 ≥ 3:1；朱红文字在月白底达标，若用于小字需加深或加粗。
- **触达区域** ≥ 48×48dp；图标按钮加透明扩展点击区。
- **动态字体**：正文支持系统字体缩放（`sp` 单位），布局用弹性约束避免截断。
- **语义**：为图标按钮、图片提供 `contentDescription`；装饰性纹样标记为 `null`（不打扰读屏）。

## 12. 验收标准

- 全局无 Material 默认紫/粉残留；主色为黛青、强调为朱红、底色为月白。
- Light/Dark 双主题切换完整，无硬编码颜色（组件只引用 `MaterialTheme.colorScheme`）。
- 底部 4 Tab、首页（搜索+轮播+导航+推荐流）、商城卡片、动态卡片、状态组件均使用统一 Token 与国风组件。

- 正文对比度与触达区域达标，图标含无障碍描述。
- `core/ui` 组件均有 Light/Dark `@Preview`，主题改造后现有页面（启动/登录/首页/商城/社交等）编译通过、视觉一致。
