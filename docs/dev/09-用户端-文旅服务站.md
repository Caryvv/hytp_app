# 09 用户端 · 文旅服务站

> 对应策划案「三、（一）4. 文旅服务站」，整合线下资源，打造"汉服+文旅"闭环。

## 1. 模块概述

基于地理位置整合本地汉服租赁、妆造、摄影、民宿、打卡地资源，提供一站式文旅套餐、在线预约核销、出行攻略，覆盖文旅游客人群（租赁/妆造/跟拍一站式需求）。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 本地服务 | P1 | 定位城市，推荐周边租赁店/妆造店/摄影师/民宿/打卡地 |
| 地图与导航 | P1 | 地图展示、导航、营业时间/口碑/价格 |
| 在线预约核销 | P1 | 预约、核销码、错峰预约 |
| 文旅套餐 | P1 | 租赁+妆造+摄影+门票+民宿一站式，热门城市定制 |
| 出行攻略 | P1 | 用户发布/浏览打卡路线、避坑指南 |
| 季节调度 | P2 | 旺季/淡季调整推荐优先级 |

## 3. 页面与交互

### 3.1 文旅服务页（3 子 Tab）
- **本地服务**：自动定位城市，周边租赁店/妆造店/打卡地列表 + 地图，支持导航、在线预约。
- **文旅套餐**：按城市分类（洛阳/西安/苏州…），展示套餐内容/价格/预约方式。
- **出行攻略**：优质用户攻略，收藏/分享。

### 3.2 本地服务详情
- 商家/服务点信息：地址、价格、口碑、营业时间；地图定位与导航；在线预约（选时段）。

### 3.3 文旅套餐详情
- 套餐组成（租赁+妆造+摄影+门票+民宿）、价格对比（vs 单独购买）、错峰预约选项、下单（走 08 订单，type=文旅）。

### 3.4 预约核销
- 预约成功生成核销码；到店由商家核销（商家端）；支持取消/改期。

### 3.5 出行攻略
- 发布：打卡路线、避坑指南、图文；浏览：平台精选攻略，按季节调优先级。

## 4. 数据模型（相关子集）

`travel_merchant`、`travel_package`、`travel_reservation`、`travel_guide`，复用 `shop`、`shop_order`、`payment`。

## 5. API 接口

### 本地服务
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/travel/merchants` | `?city=&serviceType=&lng=&lat=&sort=distance` 本地服务点 |
| GET | `/travel/merchants/{id}` | 详情 |
| POST | `/travel/reservations` | 在线预约 `{merchantId, time, ...}` |
| POST | `/travel/reservations/{id}/cancel` | 取消/改期 |
| GET | `/travel/reservations` | 我的预约（含核销码） |

### 文旅套餐
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/travel/packages` | `?city=&isOffPeak=` 套餐列表 |
| GET | `/travel/packages/{id}` | 套餐详情 |
| POST | `/orders` | 下单（type=文旅，见 08） |

### 出行攻略
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/travel/guides` | `?city=` 攻略列表（含平台精选/季节排序） |
| GET | `/travel/guides/{id}` | 详情 |
| POST | `/travel/guides` | 发布攻略 |
| POST | `/travel/guides/{id}/favorite` | 收藏 |

## 6. 端上实现要点（Android）

- `feature/travel`：3 子 Tab；本地服务用高德地图 SDK 展示 POI + 列表联动，定位权限用 accompanist-permissions。
- 距离排序：客户端传经纬度，后端按距离计算（MySQL 空间函数或应用层 Haversine）。
- 套餐下单复用 08 订单/支付；预约核销码用二维码组件生成。
- 攻略发布复用富文本/图文上传能力。

## 7. 季节调度

- `travel_guide.season` 与运营配置结合：夏季小旺季、冬季大旺季调整推荐权重（见 13 推荐 + 运营参数 `sys_config`）。

## 8. 验收标准

- 定位后能展示周边分类服务点，地图与列表联动，可导航。
- 可在线预约并生成核销码，支持取消/改期，商家端可核销。
- 文旅套餐可下单支付（type=文旅），价格展示相对单独购买的优惠。
- 可发布/浏览/收藏出行攻略，平台精选与季节排序生效。
