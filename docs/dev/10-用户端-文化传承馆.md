# 10 用户端 · 文化传承馆

> 对应策划案「三、（一）5. 文化传承馆」，强化文化内核，提升平台调性。

## 1. 模块概述

以汉服课堂（课程/回放/笔记）、历史脉络（时间轴+图鉴）、非遗专区（技艺+传承人+手作产品）承载文化传播与内容付费，是平台差异化与调性的关键。

## 2. 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 汉服课堂 | P1 | 专家/考据者课程，免费+付费，回放、笔记 |
| 青少年趣味科普 | P2 | 培养文化认同 |
| 历史脉络 | P1 | 秦汉到明清演变时间轴 + 文物图 + 讲解 |
| 汉服图鉴 | P1 | 海量实物与复原图 |
| 非遗专区 | P1 | 苏绣/缂丝/盘扣等，传承人对接，手作产品 |
| 内容付费 | P1 | 课程/考据高阶课程付费观看 |

## 3. 页面与交互

### 3.1 文化传承主页
- 三入口：汉服课堂、历史脉络、非遗专区。

### 3.2 汉服课堂
- 课程列表（分类：考据/礼仪/妆容/刺绣/青少年，免费/付费）→ 课程详情（课时列表、试看）→ 播放页（视频 + 回放 + 记笔记 + 进度）。
- 付费课程走购买（08 支付）后解锁。

### 3.3 历史脉络
- 时间轴（秦汉→魏晋→唐→宋→明→清）交互滑动，节点展开文物图 + 背景讲解。
- 关联汉服图鉴（复原图 vs 实物图）。

### 3.4 非遗专区
- 非遗技艺列表（苏绣/缂丝/盘扣）→ 详情（传承人介绍、技艺、关联手作产品）；支持线上购买（08）、线下体验预约（09）。
- 突出各产区地域文化优势。

## 4. 数据模型（相关子集）

`course`、`course_lesson`、`course_order`、`course_note`、`course_progress`、`history_timeline`、`hanfu_atlas`、`heritage`，付费复用 `payment`。

## 5. API 接口

### 汉服课堂
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/courses` | `?category=&isFree=` 列表 |
| GET | `/courses/{id}` | 详情（课时列表、是否已购） |
| POST | `/courses/{id}/purchase` | 购买 → 支付单 |
| GET | `/courses/lessons/{id}/play` | 播放地址（鉴权：免费/已购/试看） |
| POST | `/courses/notes` | 记笔记 |
| GET | `/courses/notes` | 我的笔记 |
| POST | `/courses/progress` | 上报进度（回放续播） |

### 历史脉络与图鉴
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/culture/timeline` | 时间轴节点列表 |
| GET | `/culture/atlas` | 图鉴 `?dynasty=&formeType=` |
| GET | `/culture/atlas/{id}` | 图鉴详情（复原图+实物图） |

### 非遗专区
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/culture/heritage` | `?region=` 非遗列表 |
| GET | `/culture/heritage/{id}` | 详情（传承人+关联产品） |

## 6. 端上实现要点（Android）

- `feature/culture`：三入口页；课程用列表+详情+播放（media3，支持后台记录进度）；付费解锁校验在播放接口后端做，不信任客户端。
- 历史脉络时间轴：横向可滑动的自定义 Compose 组件，节点点击展开。
- 图鉴：瀑布流（复原图/实物图对照）。
- 笔记本地草稿 Room，联网同步。

## 7. 内容付费

- 免费/付费/试看三态；付费课程购买后 `course_order` 记录，播放接口校验归属。
- 高阶考据课程面向资深同袍，可设更高定价（对齐盈利模式）。

## 8. 验收标准

- 课程免费可直接看、付费需购买后解锁、试看课时不鉴权。
- 回放可续播（进度上报生效），可记笔记并同步。
- 历史脉络时间轴可交互浏览，关联图鉴复原图/实物图对照。
- 非遗专区展示传承人与关联手作产品，可购买/预约体验。
